# ICSI 418Y PA3

Projects and project members app using React, Express, and MongoDB.

## Hhow to run

Make a `.env` file in the `server` folder with:

```
MONGO_URI=your mongodb connection string
```

Start the backend:

```
cd server
npm install
node server.js
```
Start the frontend in another terminal:

```
cd client
npm install
npm run dev
```

Then open http://localhost:5173
